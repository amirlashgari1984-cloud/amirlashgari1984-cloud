## 🚀 Featured Project

### 📦 ML-Powered Inventory Analytics Engine — v29
> **SAP B1 · Python · HDBSCAN · Isolation Forest · Excel**

An end-to-end automated analytics system connecting live to SAP via SQL, processing full inventory datasets, and generating a **23-sheet decision-ready Excel workbook** — with zero manual intervention.

#### 🔬 What it covers:

| Module | Detail |
|--------|--------|
| **ABC-XYZ Classification** | Pareto-based revenue segmentation × Coefficient of Variation (5Y periods) |
| **Demand Forecasting** | Weighted Moving Average (5Y, trend-adjusted) for next 12 months |
| **Safety Stock & Reorder** | Z=1.65 · 95% service level · EOQ optimization |
| **Dead Stock NPV** | Liquidation analysis across 3 / 6 / 12-month windows with time-value discounting |
| **Supplier Scoring** | Composite score: price stability (40%) · obsolescence risk (40%) · volume (20%) |
| **ML Segmentation** | HDBSCAN (no fixed K) · RobustScaler · log/percentile transforms |
| **Anomaly Detection** | Isolation Forest · 5% contamination · sales velocity + margin + turnover |
| **Seasonality** | Detrended decomposition (residual std / mean after linear trend removal) |
| **Multi-Echelon Inventory** | Demand-share-based optimal allocation across warehouses |
| **Cost Variance** | Cross-warehouse ItemCost drift with financial impact quantification |

#### ⚡ Results:
- **50–70% reduction** in reporting turnaround time
- **~25% improvement** in product profitability through data-driven action plans
- **~95% data accuracy** through automated validation and control frameworks
- **23 automated sheets** replacing hours of manual Excel work
